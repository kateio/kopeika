# Дзен-мани (Zen Money)

## Краткое описание

Дзен-мани — российское приложение для аналитики личных финансов с акцентом на автоматизацию. Разработано компанией **Zenmoney OU** (Эстония, основано в Санкт-Петербурге в 2010 году). Установлено более 2 млн пользователей. Ключевое преимущество — автоматический сбор данных из банков с минимальным ручным вводом.

**Платформы:** iOS, Android, веб-версия (zenmoney.ru/a/ — ограниченная поддержка).

**Модель монетизации:** Freemium с подпиской.
- **Базовый Дзен (бесплатно):** ручной ввод, учёт через SMS, базовые настройки
- **Полный Дзен (подписка):**
  - 149-249 руб/мес (зависит от тарифа)
  - 1 190-1 490 руб/год
  - Пожизненная лицензия: ~1 250-2 990 руб (разовый платёж)
  - Семейный тариф (5 пользователей): 249 руб/мес
- Пробный период: 1 неделя бесплатно для новых пользователей

**Рейтинги:**
- App Store: 4.5/5 (9 800+ оценок)
- Google Play: 4.3/5 (28 100+ оценок)

## Реализация целевых фич

### Импорт файлов

**CSV** — поддерживается. Импорт доступен через веб-версию (zenmoney.ru/a/#import). Требования к файлу:
- Каждая строка — одна операция
- Нет переносов строк внутри комментариев
- Все счета должны быть предварительно созданы с точными названиями
- Нет пустых строк
- Рекомендуемый максимум ~2 000 строк на файл
- Поддержка двух форматов: мультисчётный (со столбцами "Счёт", "Счёт-получатель", "Сумма расход", "Сумма доход") и односчётный (со столбцом "Сумма со знаком")

**OFX, QIF, PDF, Excel** — не поддерживаются напрямую, но есть Excel-конвертеры для импорта из других приложений (Деньги ОК, Acemoney, CoinKeeper, Monefy, Money Pro, HomeMoney и 12+ других).

**Импорт из банков** — главная фича. Поддержка 3 300+ банков по всему миру через API. Автоматическая синхронизация данных. Также распознавание SMS-уведомлений от крупных банков России, Украины, Беларуси. Сканирование чеков по QR-коду (платная функция).

Источники: [Загрузка данных из других сервисов](https://support.zenmoney.ru/knowledge-bases/2/articles/157-zagruzka-dannyih-iz-drugih-servisov), [Темы по CSV-импорту](https://support.zenmoney.ru/communities/1-vashi-idei-i-voprosyi/categories/44-import-csv-dannyih/topics)

### Текстовый ввод

Специального natural-language ввода (типа "500р кофе") — информация не найдена. Стандартный ввод транзакции: выбор счёта, категории, ввод суммы, опционально — комментарий, дата, метки. Упоминается "финансовый ассистент" на базе AI, которому можно задавать вопросы по финансам, строить аналитику — но про текстовый ввод транзакций через него явных данных нет.

Быстрая фиксация расходов из Push-уведомлений и SMS — пользователь получает уведомление банка и подтверждает/корректирует автоматически распознанную транзакцию.

### Голосовой ввод

Информация не найдена. Голосовой ввод транзакций в Дзен-мани не заявлен как функция приложения.

### Автокатегоризация

Поддерживается и является одной из сильнейших сторон приложения. Реализация:
- **Интеллектуальный парсинг Push-уведомлений и SMS** — алгоритм обучается и учитывает контекст при категоризации операций
- **Обучаемый алгоритм** — система корректируется на основе исправлений пользователя
- **Автоматическое распознавание торговых точек** — при импорте из банков
- **Сканирование чеков ФНС** с разбивкой по категориям (платная функция)
- **ИИ-прогнозирование расходов** по категориям на базе истории

Точность: по отзывам, качество автоматизации зависит от формата уведомлений конкретного банка. Со Сбербанком, Т-Банком, Альфа-Банком работает хорошо.

Источник: [prorosta.com](https://prorosta.com/best-personal-finance-apps-2025/)

### Кастомные категории

Поддерживается. Пользователь может создавать настраиваемые категории расходов и доходов. Также доступны:
- **Подкатегории** — поддерживаются (при импорте CSV подкатегории обозначаются через "/", например "Продукты/Молоко")
- **Метки и теги** — дополнительная система классификации операций (в платной версии)
- **Проекты и цели** — для группировки расходов

Иконки для категорий — поддерживаются.

### Графики и отчёты

Платная функция (в бесплатной версии отчёты ограничены).

В платной версии:
- Отчёты по доходам и расходам
- Тренды и анализ изменений по периодам
- Сравнение расходов в разные периоды
- "Карта расходов" (в веб-версии)
- Отчёты по "Плательщикам и получателям"
- Фильтр поиска в списке операций
- ИИ-прогнозирование будущих расходов
- Статус с ключевой информацией на одном экране
- Планирование бюджета с лимитами по категориям

Экспорт данных: поддерживается в Excel и PDF.

### PWA или нативное?

**Нативные приложения** для iOS и Android — основной продукт.

**Веб-версия** (zenmoney.ru/a/) — существует, но **официально не поддерживается**. На форуме поддержки раздел называется "Веб-версия (не поддерживается)". Пользователи активно просят возобновить поддержку. Через веб-версию доступен импорт CSV и некоторые функции, но она давно не получает обновлений.

PWA — не реализовано.

Источник: [Форум Дзен-мани — Веб-версия](https://support.zenmoney.ru/communities/1-vashi-idei-i-voprosyi/categories/4-veb-versiya-ne-podderzhivaetsya/topics)

## Что взять себе

1. **Обучаемая автокатегоризация.** Алгоритм Дзен-мани, который учится на корректировках пользователя и с каждым разом точнее определяет категории — must-have для kopeika. Особенно при текстовом/голосовом вводе: если пользователь пишет "Пятёрочка 800р", система должна запомнить, что "Пятёрочка" — это категория "Продукты".

2. **Полноценная веб-версия как конкурентное преимущество.** Дзен-мани фактически забросили свою веб-версию, и пользователи этим крайне недовольны. Поскольку kopeika — это PWA, мы можем занять эту нишу: полноценный финансовый учёт с компьютера, планшета и телефона через единый веб-интерфейс.

3. **Импорт из конкурентов.** Дзен-мани предлагает Excel-конвертеры для миграции из 12+ приложений. Для kopeika критически важно реализовать импорт CSV из популярных приложений (CoinKeeper, Дзен-мани, Monefy) — это снижает барьер перехода.
