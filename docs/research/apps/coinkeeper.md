# CoinKeeper

## Краткое описание

CoinKeeper — российское приложение для учёта личных и семейных финансов, разработанное компанией **Disrapp LLC**. Основано в 2011 году, является самым популярным приложением для учёта финансов в российском App Store. Более 350 000 активных пользователей ежемесячно, свыше 17 000 000 финансовых операций в месяц.

**Платформы:** iOS, Android, Huawei AppGallery, веб-версия (coinkeeper.me).

**Модель монетизации:** Freemium с подпиской.
- Бесплатная версия с ограниченным функционалом
- Premium-подписка: ~$3.99/мес, ~$11.99/год
- Platinum PLUS (с AI-ассистентом): до $25.99 (разовая покупка "навсегда")
- В рублях — от 899 руб/год

**Рейтинги:**
- App Store: 4.6/5 (1 600+ оценок)
- Google Play (CoinKeeper 3): 3.9/5 (10 700+ оценок)

## Реализация целевых фич

### Импорт файлов

**Импорт из файлов (CSV/OFX/QIF) — не поддерживается.** Приложение не позволяет загружать данные из файлов.

**Импорт из банков** — поддерживается для ограниченного числа российских банков: Тинькофф, Альфа-Банк, Сбербанк, ВТБ, Газпромбанк, Райффайзенбанк. Импорт осуществляется через подключение к интернет-банку (ввод данных для авторизации). Для получения новых транзакций нужно нажать кнопку "Обновить".

**Экспорт** — поддерживается экспорт данных в формате CSV.

Источник: [Помощь CoinKeeper 3 — Импорт банковских операций](http://ck3help.me/page6703845.html)

### Текстовый ввод

Поддерживается с версии 4.1 в рамках тарифа **Platinum PLUS**. Текстовый ввод доступен через AI-ассистента — можно написать что-то вроде "500 рублей кофе", и система создаст транзакцию с автоматическим определением категории.

Основной способ ввода — уникальный интерфейс с "монетками": пользователь перетаскивает монетку из кошелька/счёта в категорию расхода (drag-and-drop). Это фирменная фича CoinKeeper, создающая геймифицированный опыт.

Также доступен быстрый ввод через виджет.

### Голосовой ввод

Поддерживается в тарифе **Platinum PLUS** через AI-ассистента. Можно добавлять транзакции голосом (долгое нажатие на кнопку добавления операции или через чат с ассистентом). AI-ассистент также может анализировать расходы, показывать статистику и отвечать на вопросы по финансам.

Качество распознавания — информация не найдена в открытых источниках.

Источник: [AI ассистент CoinKeeper](https://about.coinkeeper.me/aisale)

### Автокатегоризация

Поддерживается. При включении функции "Определять категории" в профиле происходит автоматическое определение категорий для импортируемых банковских операций и распознанных SMS. Система обучается на корректировках пользователя: если категория определена неверно и пользователь исправляет её, при следующем импорте аналогичная операция будет отнесена правильно.

Источник: [Помощь CoinKeeper 3 — Импорт](http://ck3help.me/page6703845.html)

### Кастомные категории

Поддерживается. В тарифе Platinum доступно неограниченное количество пользовательских категорий доходов и расходов. Можно создавать собственные категории вместо банковских правил. Подкатегории — информация не найдена. Иконки для категорий — поддерживаются.

### Графики и отчёты

- Расширенная статистика с графиками (в Platinum-тарифе)
- Круговые диаграммы расходов по категориям
- Визуальные лимиты с цветовым индикатором ("светофор": зелёный -> жёлтый -> красный)
- Фильтры по периодам: неделя, месяц, квартал
- Комментарии и метки к операциям
- Экспорт отчётов в CSV

Источник: [Обзор на prorosta.com](https://prorosta.com/best-personal-finance-apps-2025/)

### PWA или нативное?

**Нативные приложения** для iOS и Android + **веб-версия** на coinkeeper.me. Веб-версия позволяет вводить операции и просматривать статистику с компьютера. Все данные находятся на одном экране. Однако множество пользователей жалуются, что веб-версия получает мало обновлений и поддержки. PWA не заявлено.

Источник: [CoinKeeper Web](https://blog.coinkeeper.me/coinkeeper-web-keep-up-to-date-b82c7e940e9a)

## Что взять себе

1. **Геймификация ввода транзакций.** Drag-and-drop интерфейс с "монетками" — гениальная идея, которая превращает рутинный учёт в увлекательный процесс. Для kopeika стоит продумать аналогичный игровой элемент при вводе расходов, который мотивирует пользователей вести учёт регулярно.

2. **AI-ассистент с текстовым/голосовым вводом.** Возможность написать или сказать "500р кофе" и получить готовую транзакцию — это именно тот UX, к которому нужно стремиться в kopeika. Важно, что у CoinKeeper это платная фича — мы можем сделать её доступной бесплатно как конкурентное преимущество.

3. **Визуальный "светофор" лимитов.** Цветовая индикация (зелёный -> жёлтый -> красный) при приближении к лимиту бюджета — простое и интуитивное решение, которое стоит реализовать.
