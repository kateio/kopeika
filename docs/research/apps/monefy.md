# Monefy

## Краткое описание

Monefy — простое и минималистичное приложение для трекинга расходов, разработанное компанией **Reflective Technologies ApS** (Дания). Более 11 миллионов скачиваний. Приложение позиционируется как быстрый и удобный инструмент для ручного учёта трат без привязки к банкам. Получило награду Apple "Best Budgeting App".

**Платформы:** iOS, Android. Веб-версии нет (существует неофициальный open-source проект [monefy-web](https://github.com/vandenbroucke/monefy-web) на Vue.js).

**Модель монетизации:** Freemium с разовой покупкой или подпиской.
- Бесплатная версия: базовый трекинг расходов, 15 предустановленных категорий, круговая диаграмма
- Premium: ~$1.63/мес при оплате за год или ~$59.99 разовая покупка (цены варьируются по регионам)
- Premium открывает: кастомные категории, мультисчета, тёмную тему, синхронизацию через Google Drive/Dropbox, повторяющиеся транзакции

**Рейтинги:**
- App Store: 4.7/5 (6 400+ оценок)
- Google Play: 4.9/5 (400 000+ оценок) / 3.8 (193 000 оценок — русская версия)

## Реализация целевых фич

### Импорт файлов

**Импорт из файлов — не поддерживается.** Monefy не позволяет загружать данные из CSV, OFX, QIF или других форматов.

**Экспорт** — поддерживается в CSV и Excel формате (доступен и в бесплатной версии). Данные можно экспортировать для анализа в электронных таблицах.

**Импорт из банков** — не поддерживается. Monefy принципиально не подключается к банковским счетам. Все данные вводятся вручную. Это позиционируется как преимущество с точки зрения безопасности — приложению не нужны банковские данные пользователя.

**Ручные бэкапы** — через Google Drive или Dropbox (Premium). Можно перенести данные между устройствами через файл бэкапа (email, AirDrop).

### Текстовый ввод

**Natural-language ввод — не поддерживается.** Нельзя написать "500р кофе" для создания транзакции.

Стандартный ввод: нажатие "+" или "-" на главном экране -> выбор категории из круговой диаграммы -> ввод суммы на калькуляторе -> готово. Ввод транзакции занимает 2-3 секунды и 2 нажатия. Это одно из главных преимуществ — максимальная скорость ручного ввода.

### Голосовой ввод

Не поддерживается. Голосовой ввод транзакций в Monefy отсутствует.

### Автокатегоризация

Не поддерживается. Все транзакции категоризируются вручную пользователем при вводе. Нет ни ML-алгоритмов, ни правил, ни обучения. Пользователь сам выбирает категорию каждый раз.

### Кастомные категории

**В бесплатной версии** — только 15 предустановленных категорий с иконками (еда, транспорт, развлечения и др.). Создание своих категорий **недоступно**.

**В Premium** — неограниченное количество кастомных категорий с персонализированными названиями и цветными иконками (например, иконка духовки для газа, термометр для медицинских расходов).

**Подкатегории** — не поддерживаются. Пользователи отмечают это как недостаток: "It would be helpful to have a sub category option" (источник: [justuseapp.com](https://justuseapp.com/en/app/1212024409/monefy-money-tracker/reviews)).

**Важно:** изменение категории влияет на все предыдущие транзакции, использовавшие эту категорию.

### Графики и отчёты

**Круговая диаграмма (donut chart)** — основной и единственный тип визуализации. Отображается на главном экране приложения:
- Разбивка расходов по категориям в процентах
- В центре — суммы прихода, начального баланса и расходов
- При нажатии на сегмент — детальный список операций с наименованием, датой и суммой

**Фильтры по периодам:** день, неделя, месяц, год, произвольный период.

**Режим бюджета:** при включении на диаграмме отображается зелёное кольцо прогресса и процент оставшегося бюджета.

**Экспорт отчётов:** CSV и Excel.

Продвинутых отчётов (тренды, сравнения периодов, прогнозы) — нет.

### PWA или нативное?

**Только нативные приложения** для iOS и Android. Официальной веб-версии нет. PWA не реализовано.

Существует неофициальный open-source проект **monefy-web** (github.com/vandenbroucke/monefy-web) на Vue.js, который позволяет визуализировать экспортированные из Monefy данные в браузере, но это не официальный продукт.

Источник: [monefy-web на GitHub](https://github.com/vandenbroucke/monefy-web)

## Что взять себе

1. **Скорость ввода транзакции.** 2-3 секунды на ввод — золотой стандарт для ручного учёта. Для kopeika нужно обеспечить аналогичную скорость: один тап для выбора категории + ввод суммы = готово. Круговая диаграмма с категориями на главном экране — отличный UX-паттерн для быстрого доступа.

2. **Принцип "privacy-first".** Monefy доказывает, что приложение для учёта финансов может быть успешным (11 млн скачиваний) без банковских интеграций. Для kopeika стоит сделать ручной ввод основным режимом и не требовать банковских данных — это снимает барьер доверия у новых пользователей.

3. **Модель Lifetime-покупки.** Пользователи ценят отсутствие ежемесячных платежей. Для kopeika стоит рассмотреть вариант разовой покупки Premium наряду с подпиской — это привлекает аудиторию, уставшую от подписочной модели.
