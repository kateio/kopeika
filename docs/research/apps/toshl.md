# Toshl Finance

## Краткое описание

**Toshl Finance** — приложение для управления личными финансами от словенской компании **Toshl** (Любляна, Словения). Более 2 миллионов пользователей. Отмечено New York Times как *"one of the hardest to beat"* среди приложений для мониторинга расходов. Известно уникальным дизайном с персонажами-монстрами.

- **Платформы:** iOS, Android, Web (toshl.com)
- **Модель монетизации:** Freemium с тремя планами:
  - **Free:** 2 финансовых аккаунта, 2 бюджета, базовый функционал
  - **Toshl Pro:** $2.99/мес или $19.99/год — безлимитные аккаунты и бюджеты, фото чеков, повторяющиеся расходы, напоминания о счетах, биометрическая разблокировка
  - **Toshl Medici:** $4.99/мес или $39.99/год — все фичи Pro + автоматический импорт из банков (США/Канада)
- **Рейтинги:** 4.7/5 в App Store (1.8K отзывов)
- **Разработчик:** Toshl d.o.o., Любляна, Словения

## Реализация целевых фич

### Импорт файлов

Toshl поддерживает **8 форматов импорта**: CSV, OFX, QFX, TSV, TAB, XLS, TXT и QIF. Это один из самых широких наборов среди конкурентов.

Особенности:
- Импорт доступен **только через веб-приложение** (не в мобильных)
- Загрузка файлов через кнопку или drag-and-drop
- Для CSV и XLS файлов — интерфейс **маппинга колонок**: сопоставление столбцов файла с полями Toshl (дата, категория, описание, теги)
- Разработчики рекомендуют OFX, QFX или QIF — они "лучше структурированы для финансовых данных"
- Необходимо выбрать целевой счёт перед импортом
- Автокатегоризация при импорте не упоминается — маппинг категорий ручной

**Источник:** [Toshl Blog — How to Import](https://toshl.com/blog/how-to-import-financial-data-web-app/)

### Текстовый ввод

**Natural-language ввод не поддерживается** нативно. Ввод транзакции выполняется за "4 тапа" через стандартную форму: сумма, категория, теги, сохранение.

Существует сторонний проект на GitHub — [Toshl WebApp Chat](https://github.com/hoandesign/toshl-webapp-chat-public) — чат-интерфейс на Google Gemini для управления данными Toshl через natural language, но это не официальная функция.

### Голосовой ввод

**Не поддерживается нативно.** Упомянутый выше сторонний проект включает голосовой ввод через микрофон, но это не часть официального приложения.

### Автокатегоризация

Toshl использует **двухуровневую систему** автокатегоризации:

1. **Начальная категоризация** — партнёры по банковскому подключению (Salt Edge, Plaid) проводят "анонимный совокупный анализ миллионов транзакций" для определения категорий
2. **Персональная категоризация** — система учится на исправлениях пользователя: *"Toshl будет учиться из ваших прошлых выборов и применять их к новым расходам"*

Улучшение идёт двумя путями:
- Коллективные данные пользователей улучшают категоризацию отдельных магазинов
- Личные корректировки быстро адаптируют систему под индивидуальные паттерны

**Источник:** [Toshl Blog — Spending Categories That Learn](https://toshl.com/blog/spending-categories-that-learn-from-you/amp/)

### Кастомные категории

- **Полная свобода** создания, редактирования и удаления категорий
- **Теги** используются вместо подкатегорий — они кросс-категорийные (один тег может применяться в разных категориях)
- Каждая запись имеет **одну категорию** и **множество тегов**
- Иконки для категорий предустановленные (монстры Toshl)

**Источник:** [Toshl Blog — Edit Categories and Tags](https://toshl.com/blog/edit-categories-and-tags-web-app/amp/)

### Графики и отчёты

Богатый набор визуализаций:
- **River Flow** — уникальная визуализация денежного потока в виде реки (фирменная фича Toshl)
- **Bar charts** — сравнение расходов по категориям с процентным отличием от предыдущих периодов
- **Line charts** — тренды расходов по категориям тегов за период
- **Bubble charts** — размер пузыря зависит от доли в расходах (ограничение: сложно различать при более чем 3 категориях)
- **Pie charts** — круговые диаграммы
- **Expense Map** — карта расходов по геолокации
- Фильтры по периодам, категориям, тегам
- Еженедельные/ежемесячные/ежегодные email-отчёты с инфографикой
- Экспорт данных в нескольких форматах

**Источник:** [FusionCharts — Toshl Dashboard Review](https://www.fusioncharts.com/blog/personal-finance-apps-with-amazing-dashboards-part-2-toshl-finance/)

### PWA или нативное?

- **Нативные приложения** для iOS и Android
- **Web-приложение** на toshl.com (полноценное, не PWA)
- Синхронизация через облако между всеми платформами
- Информация о PWA не найдена — скорее всего, не поддерживается

### Дополнительно: OCR чеков

- На iOS 15+ — сканирование текста чека камерой и вставка в поле расхода
- На Android — через Google Lens
- Отсканированный текст остаётся доступным для поиска в приложении
- Фото чеков можно сохранять (Toshl Pro и выше)

## Что взять себе

1. **River Flow визуализация** — уникальная и запоминающаяся диаграмма денежного потока, которая стала фирменной фичей Toshl. Для kopeika стоит продумать свою "signature visualization", которая выделит приложение среди конкурентов.
2. **Кросс-категорийные теги** вместо жёсткой иерархии подкатегорий — более гибкая система, позволяющая одну покупку отмечать несколькими тегами из разных контекстов (например, "подарок" + "день рождения" + "одежда").
3. **8 форматов импорта** — самый широкий набор среди исследуемых приложений. Для kopeika как PWA стоит поддержать хотя бы CSV, OFX и QIF для максимального охвата пользователей, мигрирующих из других приложений.
