# Spendee

## Краткое описание

**Spendee** — приложение для управления бюджетом и отслеживания расходов от чешской компании **SPENDEE a.s.** (Прага). Около 3 миллионов пользователей по всему миру. Известно фокусом на визуализацию финансов и красивый дизайн интерфейса.

- **Платформы:** iOS, Android, Web (app.spendee.com)
- **Модель монетизации:** Freemium с тремя планами:
  - **Basic (бесплатно):** 1 бюджет, 1 кошелёк, подключение аккаунтов, без шеринга
  - **Spendee Plus:** $1.99/мес или $14.99/год — безлимитные бюджеты и кошельки, общие кошельки
  - **Spendee Premium:** $2.99–5.99/мес или $22.99–35.99/год — автокатегоризация, банковская синхронизация, бэкап данных
  - **Lifetime Premium:** $44.99–119.99
- **Рейтинги:** 4.6/5 в App Store (6.1K отзывов), 4.6/5 в Google Play
- **Разработчик:** SPENDEE a.s., Прага, Чехия

## Реализация целевых фич

### Импорт файлов

Spendee поддерживает импорт в форматах **CSV, XLS и XLSX**.

Особенности:
- Максимальный размер файла: **10 МБ**
- Обязательные поля: формат даты, дата, название категории, сумма
- Импорт возможен **только в кошельки наличных** (не в подключённые банковские счета)
- Импорт выполняется через **веб-приложение** (app.spendee.com)
- **Нет защиты от дублирования** — система не определяет уже внесённые транзакции
- Автокатегоризация при импорте **не работает** — переводы между счетами не распознаются автоматически
- OFX, QIF, PDF — **не поддерживаются**

**Источник:** [Spendee Help Center — Import](https://help.spendee.com/article/121-import-transactions)

### Текстовый ввод

**Natural-language ввод не поддерживается.** Ввод транзакции через стандартную форму: выбор категории, сумма, описание, фото, локация. Интерфейс описывается как "super easy to use and intuitive".

### Голосовой ввод

**Не поддерживается.** Нет упоминаний голосового ввода в документации или отзывах.

### AI Receipt Scanner (сканер чеков)

Новая фича — **AI Receipt Scanner**: сканирование чека камерой с автоматическим извлечением цены, категории, описания и фото. Создание транзакции "in seconds". Доступно на iOS и Android.

**Источник:** [Google Play](https://play.google.com/store/apps/details?id=com.cleevio.spendee&hl=en_US)

### Автокатегоризация

Spendee использует автоматическую категоризацию для банковских транзакций:
- Анализирует данные о торговце и описание операции из банка
- Использует **машинное обучение** с запоминанием предпочтений пользователя
- Требуется **4–5 ручных корректировок** с синхронизацией для обучения
- Точность зависит от объёма данных, предоставляемых банком
- **Не работает** для банков, подключённых через собственный API
- Доступна только в **Premium** подписке

**Источник:** [Spendee Help Center — Automatic Categorization](https://help.spendee.com/article/179-automatic-categorization)

### Кастомные категории

- **Полная свобода** создания кастомных категорий
- Можно добавлять **фото и локацию** к каждому расходу
- Вместо подкатегорий используются **Labels (метки)** — множественные теги к транзакции
- Пример: категория "Food & Drink" + метки "pizza", "restaurant", "takeaway"
- Иконки и цвета настраиваемые

**Источник:** [Spendee Help Center — Labels](https://help.spendee.com/article/237-what-are-labels-and-how-to-use-them)

### Графики и отчёты

- **Line chart** — линейный график доходов/расходов за период
- **Pie chart** — круговая диаграмма расходов по категориям с процентами
- **Cash flow** — анализ входящих и исходящих транзакций
- Уведомления при приближении к лимиту бюджета
- Экспорт данных (CSV/XLS)
- Фильтры по периодам и категориям в веб-версии
- **Dark mode** поддерживается

**Источник:** [Spendee](https://www.spendee.com/), [App Store](https://apps.apple.com/us/app/spendee-budget-app-planner/id635861140)

### PWA или нативное?

- **Нативные приложения** для iOS и Android
- **Web-приложение** на app.spendee.com — дополняет мобильное приложение
  - Расширенные возможности: bulk edit транзакций, импорт CSV/XLS, детальный анализ, расширенные фильтры
  - Ограничение: управление подпиской — **только через мобильное приложение**
- PWA как таковое **не реализовано**

**Источник:** [Spendee Help Center — Web App](https://help.spendee.com/article/199-spendee-web-app)

### Плюсы

- *"Super easy to use and intuitive"* с *"clear"* визуализацией и *"nice"* цветовыми схемами — App Store
- *"The best thing about Spendee are charts"* — графики с процентным представлением категорий — обзоры

- Общие кошельки для семей/пар/соседей — уникальная фича
- Поддержка крипто-кошельков (Coinbase) — не у всех конкурентов
- Отсутствие рекламы в бесплатной версии — App Store
- AI Receipt Scanner — новая удобная фича

### Минусы

- *"Connecting to bank accounts was a hassle... many times it could not connect"* — [G2](https://www.g2.com/products/spendee/reviews)
- *"Very annoying to have to switch to another screen"* для просмотра остатка бюджета — App Store
- Нет виджета для экрана и нет версии для iPad — обзоры
- Нет инвестиционного трекинга — [Capterra](https://www.capterra.com/p/238829/Spendee/reviews/)
- Кредиты и займы некорректно считаются в net worth (добавляются вместо вычитания) — Reddit
- Импорт только в cash wallets, не в банковские аккаунты — [Help Center](https://help.spendee.com/article/121-import-transactions)
- Нет защиты от дублирования при импорте
- Автокатегоризация не работает для некоторых банковских API

## Что взять себе

1. **Shared Wallets (общие кошельки)** — уникальная фича для пар, семей и соседей. Для kopeika стоит продумать collaborative finance tracking как дифференциатор.
2. **AI Receipt Scanner** — сканирование чека камерой с автозаполнением всех полей транзакции. Для PWA можно реализовать через Web Camera API + OCR-сервис.
3. **Простота ввода + визуальный акцент** — Spendee показывает, что красивые графики и минималистичный UX ввода расхода важнее количества фич. Для kopeika стоит сделать ввод транзакции максимально быстрым (целевое — 3-4 тапа) с immediate visual feedback.
