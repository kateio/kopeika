## Структура

### Общий layout
Приложение обёрнуто в **iOS device frame** (402×874px) с Dynamic Island, статус-баром (9:41, сигнал, Wi-Fi, батарея) и home indicator — имитация iPhone 15 Pro. Фрейм рендерится на фоне с радиальным градиентом (`#ECE7DD` → `#C9C3B6`).

### Экраны

1. **StartScreen** — онбординг / настройка категорий
   - Логотип (лаймовый квадрат 104×104 с иконкой графика)
   - Заголовок «Копейка» + описание
   - Сетка toggle-кнопок для выбора категорий (вкл/выкл)
   - Кнопка «+ добавить» для пользовательских категорий (с inline-инпутом)
   - CTA-кнопка «Поехали»

2. **MainScreen** — основной экран с данными
   - Заголовок с названием месяца (дропдаун) + аватар «К»
   - Переключатель «траты / доходы» (сегментированный контрол)
   - Кольцевая диаграмма (donut chart) с суммой в центре
   - Список категорий с процентами и суммами
   - Поле ввода внизу с кнопкой скрепки (прикрепить выписку) и кнопкой отправки

3. **CategoryModal** — bottom sheet детализации
   - Grabber + заголовок с цветовой точкой
   - Общая сумма и количество операций
   - Список транзакций (название, дата, сумма)
   - Закрывается кликом по оверлею или крестиком

4. **Month Picker** — выпадающий список из 12 месяцев с подсветкой текущего

### Типографика
- **Основной шрифт:** `Inter Tight` (400, 500, 600, 700), загружается с Google Fonts
- **Fallback:** `-apple-system, system-ui, sans-serif`
- **iOS frame:** `-apple-system, "SF Pro", system-ui` для статус-бара и клавиатуры
- **Размеры:** 32px (заголовок «Копейка»), 28px (месяц), 30px (сумма в диаграмме), 16–17px (основной текст), 13–15px (описания и метки), 11–12px (капсы/лейблы)
- **Letter-spacing:** от -0.8 (заголовки) до 0.6 (uppercase-метки)

### Скругления
- Настраиваемый `radius` через TweaksPanel (4–28px, по умолчанию 16px)
- CTA-кнопка: `radius + 6`
- Карточки: `radius + 4`
- Category modal: 28px (фиксированный)
- Device frame: 48px (фиксированный)
- Toggle-кнопки категорий: `radius`

### Отступы
- Основные padding: 24px (горизонтальный контент), 16px (списки и карточки)
- Вертикальные отступы между блоками: 12–16px
- Padding сверху: 60–64px (под status bar + Dynamic Island)
- Нижний padding CTA: 40px

## Состояния и интерактив

### Реализованные состояния
- **Навигация** между Start и Main (кнопка «Поехали» / «← старт»)
- **Режим трат/доходов** — переключатель перефильтровывает данные и меняет label диаграммы
- **Выбор месяца** — дропдаун, данные перефильтровываются (заданы моки для апреля и марта)
- **Toggle категорий** — включение/выключение на стартовом экране
- **Добавление категории** — inline-инпут с `onBlur` и `Enter`
- **Ввод транзакции** — наивный парсинг текста (`"еда 500"` → категория + сумма)
- **Прикрепление выписки** — toast с подсказкой (пока только UI, без реальной загрузки)
- **Модалка категории** — открытие по клику, закрытие по оверлею / крестику
- **Подсветка отправки** — кратковременная подсветка рамки инпута при отправке
- **Persistence** — экран, категории, транзакции и tweaks сохраняются в `localStorage`

### Мок-данные
- 8 категорий расходов (5 включены по умолчанию, 3 выключены)
- 2 категории дохода (зарплата, фриланс)
- ~12 транзакций-примеров за апрель и март 2026
- Суммы в рублях, форматирование через `Intl.NumberFormat('ru-RU')`

### Анимации
- `fadeIn` (opacity 0→1) — для overlay модалки
- `slideUp` (translateY 20→0 + opacity) — для toast и модалки
- CSS transitions на кнопках (0.15s)

## Технические замечания

### Архитектура наброска
Набросок построен как **single HTML + 3 JSX** файла, загружаемых через CDN:
- React 18.3.1 (development UMD build)
- ReactDOM 18.3.1
- Babel Standalone 7.29.0 (JIT-компиляция JSX в браузере)

Компоненты экспортируются через `Object.assign(window, {...})` — глобальный scope вместо ES-модулей.

### Что нужно для перехода в production

1. **Сборка:** заменить Babel Standalone + CDN на Vite/Next.js/Remix с нормальной сборкой
2. **Модули:** перейти с `window.*` на ES-модули (`import/export`)
3. **Стили:** вынести inline-стили в CSS Modules, Tailwind или styled-components — сейчас 100% inline `style={{}}`, что затрудняет поддержку и медиа-запросы
4. **State management:** `useState` + prop drilling → рассмотреть Zustand/Context для глобального состояния (тема, транзакции, категории)
5. **Persistence:** `localStorage` → серверное хранение или хотя бы IndexedDB
6. **Роутинг:** ручное переключение по `screen` state → React Router или файловый роутинг
7. **Типизация:** добавить TypeScript — сейчас всё на JS без типов
8. **Парсинг транзакций:** наивный `String.includes()` → NLP или структурированный ввод
9. **Загрузка выписок:** реализовать парсинг CSV/PDF выписок банков
10. **Адаптивность:** жёстко заданные размеры (402×874) → responsive layout
11. **Шрифты:** загрузка Inter Tight с Google Fonts → self-hosted или system font
12. **Безопасность:** нет санитизации ввода, нет валидации данных
13. **Тестирование:** нет тестов — добавить unit и e2e

### Качество наброска
Для дизайн-наброска качество **высокое**:
- Чистый, читаемый код без мусора
- Продуманная система дизайн-токенов (тема, акценты, радиусы)
- Реалистичный iOS 26 device frame с liquid glass эффектами
- Рабочая интерактивность (не просто картинки, а полноценные состояния)
- Локализация на русском (интерфейс, данные, форматирование)
- Persistence через localStorage — состояние сохраняется между перезагрузками
