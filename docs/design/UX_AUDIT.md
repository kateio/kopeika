# UX-аудит kopeika v1

Сравнение текущего UI (Этап 1, PR #3, ветка `feat/stage1-scaffold-7e8f2d9`) с выводами
research конкурентов (`docs/research/`).

**Дата:** 2026-04-30
**Источники:** 11 приложений — CoinKeeper, Дзен-мони, Monefy, Money Lover, Tinkoff,
YNAB, Wallet, Toshl, Spendee, Mint, Finly.

---

## TL;DR

Обновлено 2026-05-01: учтены 4 архитектурных решения пользователя — см. раздел «Архитектурные решения» ниже.

1. **Нет CRUD транзакций** — нельзя отредактировать или удалить введённую операцию.
   Это есть у *всех* 11 конкурентов. Критичный gap.
2. **Нет хронологического списка транзакций** — пользователь видит операции только
   через drill-down по категории. Все конкуренты показывают общий список с группировкой
   по дням.
3. **Фильтр только по месяцу** — у Monefy, YNAB и Tinkoff есть день/неделя/год/произвольный
   период. При одном месяце невозможно оценить динамику.
4. **Emoji-иконки не показываются** — типы и мок-данные уже содержат emoji (`🍕`, `🚌`, `💅`),
   но UI рендерит только цветные точки. Простейшее улучшение узнаваемости категорий.
5. **InputBar конфликтует с bottom navigation** — если добавлять tab bar (а это нужно
   для Settings/транзакций), фиксированный инпут внизу не поместится. Нужно решение.

## Архитектурные решения пользователя (зафиксированы 2026-05-01)

> Эти решения уже приняты и не подлежат обсуждению в чеклисте.

### Решение 1. Bottom navigation — НЕ делаем

У приложения всего 2 верхнеуровневых раздела:
- **Main** (основной экран — траты/доходы, donut, ввод)
- **Settings** (модальный экран, открывается через тап по аватарке «К» в шапке Main)

Bottom nav не нужен. Если в будущем добавятся бюджеты/аналитика/импорт — решение будет
пересмотрено (модальные экраны через шапку, drill-down с Main, или возврат к bottom nav
при 3+ разделах).

**Снято:** B1 (Bottom navigation) из категории B.

### Решение 2. Шторка категории → drill-down фильтр «на месте»

**Было:** клик по категории открывает CategoryModal (шторку) с детализацией.

**Стало:** клик по категории на donut chart переводит экран в **режим фильтра**:
- Donut перерисовывается, выделяя только выбранную категорию
- Список транзакций ниже фильтруется только по этой категории
- Шапка/индикатор показывает «Активный фильтр: \<Категория\>»
- Повторный клик по той же категории (или крестик «×») — снимает фильтр

Паттерн drill-down фильтрации на одном экране — как у **Tinkoff** и **YNAB Mobile** — без модалок.

**Затронуто:** A1, A2, B2, B5, D1, D5 (новый).

### Решение 3. Микрофон — НЕ делаем сейчас

iOS клавиатура имеет встроенный голосовой ввод (микрофон возле пробела). Отдельная иконка
микрофона в нашем UI дублирует системную функцию и добавляет визуальный шум.

Голосовой ввод вернётся в Этапе 3+, когда будет реализована запись аудио → Whisper API
через backend (полноценный голосовой ввод аудио-сэмпла, не текстовый).

**Снято:** B6 (Микрофон / голосовой ввод) из категории B.

### Решение 4. Quick-add — умный контекстный InputBar

Никакого FAB / плавающего плюсика / плюсика в шапке. Quick-add работает через
**существующий InputBar внизу**, но он становится **контекстным**:

- **Без фильтра** (общий вид Main): пишешь «500 кофе» → автокатегоризация определяет
  категорию → добавляется транзакция
- **С активным фильтром по категории** (drill-down): пишешь «500 кофе» → транзакция
  автоматически идёт в выбранную категорию, без определения категории

Новых UI-элементов не добавляется — меняется только поведение существующего InputBar.

**Затронуто:** B7 (Quick-add), D3 (конфликт InputBar/bottom nav — снят).

## Что есть в текущем UI

### Экраны

| Экран | Что делает | Ключевые элементы |
|-------|-----------|-------------------|
| **StartScreen** | Онбординг — выбор категорий | Логотип, tagline, toggle-чипсы категорий, inline-добавление своей категории, CTA «Поехали» |
| **MainScreen** | Основной дэшборд | MonthPicker, SegmentedControl (траты/доходы), DonutChart (3 стиля), CategoryList с %, InputBar (NL-ввод), кнопка 📎 (stub) |
| **CategoryModal** | Bottom sheet детализации | Заголовок с CatDot, итого, flat-список транзакций (note + date + amount) |
| **UIKitPage** | Каталог компонентов (/uikit) | Все компоненты во всех состояниях, палитра, типографика |

### Реализованные фичи

- Ввод транзакции через NL-текст (`"еда 500"` → naive parsing)
- Donut chart с динамической oklch-палитрой (3 стиля: ring/pie/thin)
- Переключатель трат/доходов (SegmentedControl)
- Выбор месяца (MonthPicker dropdown)
- Drill-down по категории (CategoryModal bottom sheet)
- Кнопка 📎 с toast-заглушкой о прикреплении выписки
- PWA-манифест, apple-touch-icon, iOS meta-теги, service worker
- TypeScript типы с multi-currency (`Money`, `CurrencyCode: 'RUB' | 'USD'`)
- 47 мок-транзакций (RUB + USD) в `src/data/mocks.ts`
- 12 категорий с emoji в данных
- Утилиты `formatMoney`, `groupByCategory`, `groupByDay` (определены, но не подключены к экранам)
- React Router (3 роута), Vite, TailwindCSS, Vitest (14 тестов)

### Чего нет (и не было в наброске)

- Редактирование/удаление транзакций
- Хронологический список всех транзакций
- Полноценный Settings экран
- Bottom navigation (tab bar)
- Поиск и фильтрация
- Группировка транзакций по дням
- Персистентность данных (localStorage убрали из прототипа, IndexedDB ещё нет)
- Тёмная тема (токены определены, переключатель не реализован)
- Голосовой ввод (заявлен в tagline, нет кнопки)
- Реальный импорт файлов

## Группировка предложений по экранам

### StartScreen (онбординг)

Текущий экран — хороший. Минимальные изменения:
- **B3**: Показывать emoji внутри CatDot на toggle-чипсах категорий

### MainScreen (основной дэшборд)

Основной экран значительно расширяется — становится единым хабом для просмотра и ввода:

- **A1**: Редактирование/удаление транзакций — тап по транзакции → редактор, свайп-влево → удалить
- **A2**: TransactionList под donut — хронологический список с группировкой по дням
- **A3**: Заменить MonthPicker → PeriodPicker (месяц + год + custom range)
- **A4**: Toast с подтверждением при добавлении транзакции + undo
- **B3**: Emoji в CatDot категорий
- **B5**: Группировка транзакций по дням (sticky-заголовки)
- **B7**: InputBar становится контекстным (Решение 4): без фильтра — автокатегоризация, с фильтром — категория предопределена
- **B8**: Символ валюты в суммах
- **Drill-down фильтр** (Решение 2): тап по категории на donut → фильтрация списка транзакций и визуальное выделение категории. Паттерн Tinkoff / YNAB Mobile
- **D1**: В TransactionList — единый список с цветовой меткой (без tabs трат/доходов)
- **D2**: Аватар «К» → кнопка перехода в Settings (модальный экран)
- **D4**: Парсинг-превью перед подтверждением
